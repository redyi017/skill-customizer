# 0003 Write skills in English

- Date: 2026-10-17
- Status: Accepted. The part about documentation language is superseded by ADR 0005.

## Context

What language should the skills in `skills/` be written in?

## Options

1. English.
2. Traditional Chinese.

## Decision

Skills (SKILL.md and the files it references) are written in English. At the time, `docs/` and the ADRs stayed in Traditional Chinese; ADR 0005 later moved all repo content to English.

## Rationale

- All sources are in English, so wording can be borrowed without translation or loss of meaning.
- A skill's description decides when it triggers, and English descriptions trigger more reliably.
