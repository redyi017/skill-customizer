# 0004 公開 repo 的授權與第三方內容處理

- 日期：2026-10-17
- 狀態：已採用

## 背景

repo 要公開在 GitHub。四套來源的授權不同：

- Matt Pocock skills、pstack：MIT。
- Anthropic skills：多數為 Apache 2.0；docx、pdf、pptx、xlsx 為專有授權，禁止複製、在服務以外保留副本、衍生與散布。
- Claude Code plugins：all rights reserved，非開源。

## 決定

1. **原始檔不進 repo**：`sources/` 列入 `.gitignore`，由 `scripts/fetch_sources.py` 依 `scripts/sources.json` 的固定 commit 抓到本機。四個專有授權的 Anthropic skill 不抓取。
2. **面向庫用自己的話寫**：描述做法並附連結；引用只用短句，對非開源來源盡量不引用。
3. **寫 skill 時依授權處理**：
   - MIT、Apache 來源：可以借用寫法，但要在該 skill 資料夾註明出處，並在 `THIRD_PARTY_NOTICES.md` 附上版權與授權聲明；Apache 來源還要註明修改內容。
   - 非開源來源：只借用想法，文字與程式碼自己寫。
4. **本 repo 採用 MIT 授權**（`LICENSE`）。

## 原因

- 不散布別人的檔案，就沒有散布授權的問題，同時仍能用 commit 追溯原文。
- MIT 與 MIT、Apache 的內容相容，也讓別人清楚知道能怎麼使用這些 skill。
- 這是依授權條款整理的一般做法，不是法律意見；若要商業使用，應另請專業人士確認。
