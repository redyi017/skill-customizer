# 0002 既有 skill set 整理成面向庫，不每次重讀

- 日期：2026-10-17
- 狀態：已採用

## 背景

每次建立或調整 skill 時，要回頭參考既有 skill set 的原始文件，還是先整理成可以累積的形式？

## 選項

1. 每次都參考原始文件。
2. 每套來源只完整讀一次，整理進面向庫；之後只用面向庫，新增來源時只收錄新的那套。
3. 整理後刪除原始文件。

## 決定

採用選項 2。原始檔保留在 `sources/` 當存檔並固定 commit，但不是日常參考的資料。

## 原因

- 面向庫可以累積：新增一套來源，只要把它對應到既有面向，再補上新面向。
- 不用每次重讀，節省時間和 context。
- 整理一定會遺失細節，所以保留原文和出處，第 4 階段借用寫法時，或摘要不夠時，仍然可以查。
- 選項 3 讓決定無法追溯，因此不採用。
