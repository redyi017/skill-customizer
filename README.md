# SkillCustomizer

A personal workflow skill set for Claude Code. The first domain is coding.

Instead of adopting one existing skill set wholesale, this repo extracts the design *dimensions* that existing skill sets take positions on (who decides, how much planning, how work is verified, …), lets me choose my own position on each, and builds skills from those choices.

- Working agreement and repo rules: [`CLAUDE.md`](CLAUDE.md)
- Method: [`docs/method.md`](docs/method.md)
- Dimension catalog: [`docs/dimensions.md`](docs/dimensions.md)
- Sources: [`docs/sources.md`](docs/sources.md)
